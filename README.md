
# Vehicle Rental System

# Description
The Vehicle Rental System is a simple Java application developed as a group practical project for OOP.

The application is designed to help user manage vehicle rental activities through a Graphical User Interface (GUI) built using Java Swing.

## Features
- Simple graphical user interface.
- Vehicle rental management.
- Object-oriented programming using Java classes.
- User interaction through the application interface.

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)

## Project Requirements
This project demonstrates:
- Classes and Objects
- Constructors
- Encapsulation
- Methods
- Conditional statements
- Loops
- Arrays

## How to Run
1. Download or clone this repository.
2. Open the project in your Java IDE.
3. Locate the main Java file.
4. Run the main class.
